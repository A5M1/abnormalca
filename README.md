# Abn Cert Installation Assistant (ACIA)

> **Manifesto:** *Software Security Should NEVER Be Controlled By Corporations.*

## Overview

Security and device trust belong to the user, not proprietary OS vendors or corporate gatekeepers. **The Abn Cert Installation Assistant (herein referred to as ACIA)** is an open-source manager whose primary purpose is to provision CA, EV, and OV security certificates issued by ABN-Software directly into Windows certificate stores.
